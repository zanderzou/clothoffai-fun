If someone sends a link to a manipulated intimate image, preserve the information that identifies the post without forwarding the content. Australia's eSafety Commissioner recommends keeping the web address, account details and timing when gathering evidence. The FTC also describes reporting options for image-based abuse.

## Note where it was shared

Write the post or message link where available, the displayed account name, and the time you saw it. In a private message, note which service received it and where its report control appears. A useful description says that the image appears altered and was shared without your permission. Avoid downloading or forwarding restricted material.

## Record the result of the report

Use the platform's reporting route or an eligible service relevant to your location. Save the confirmation and any case number. For another post, record its exact location separately even if the original image appears the same.
