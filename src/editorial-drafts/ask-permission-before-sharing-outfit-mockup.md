Use your own image or get agreement from the adult shown before making and sharing an outfit mock-up. The eSafety Commissioner explains consent for sharing images. Make the request specific enough that everyone can recognize the same edit and the audience it will reach.

## Ask about one image and its use

Suppose a friend offers a photo of themselves wearing a winter coat. Ask whether you may make a mock-up of the same full coat in another color, then show only the agreed preview privately. Ask separately before using it in a public gallery. Show them the final preview and describe the planned audience.

## Keep the approved version identifiable

Save the file name, agreed destination and date in your own records. If you change the crop, purpose or audience, check with the person again. Add a visible label that says the outfit color was edited, so a viewer knows what the preview shows.
